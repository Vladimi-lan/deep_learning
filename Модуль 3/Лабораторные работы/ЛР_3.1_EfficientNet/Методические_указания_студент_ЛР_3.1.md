# Методические указания для студентов по выполнению ЛР № 3.1

## Введение

Работа посвящена **трём способам построения моделей в Keras**. Архитектура CNN одна и та же — меняется только API. Transfer Learning / Fine-tuning изучаются отдельно в **ЛР 4.1**.

## Ход выполнения работы

### 1. Подготовка данных

1. Загрузите CIFAR-10 (`tf.keras.datasets.cifar10`) либо Flowers — по заданию преподавателя.
2. Нормализуйте пиксели в `[0, 1]` (`/ 255.0`).
3. Для train добавьте аугментацию (`RandomFlip`, `RandomRotation` и т.п. через Keras layers или ImageDataGenerator).
4. Выделите validation split.

**Вопрос 1.** Почему аугментация помогает бороться с переобучением?

### 2. Общая архитектура CNN

Зафиксируйте одну архитектуру, например:

*   Conv(32) → Conv(32) → MaxPool → Dropout
*   Conv(64) → Conv(64) → MaxPool → Dropout
*   Flatten / GAP → Dense(128) → Dropout → Dense(num_classes, softmax)

### 3. Три реализации

1. **Sequential** — линейный стек слоёв.
2. **Functional** — явные связи тензоров.
3. **Subclassing** — класс с методом `call`.

Обучите каждую модель с одинаковыми гиперпараметрами (optimizer, epochs, batch size).

# Методические указания для преподавателей по проведению ЛР № 3.1

## Тема и цель работы

**Тема:** Сравнение Sequential / Functional / Subclassing API в Keras на задаче классификации изображений.

**Цель:** Научить студентов выбирать способ описания модели под сложность архитектуры. Transfer Learning вынесен в ЛР 4.1.

## Компетенции

*   **DL-1.4 (Средний):** построение CNN.
*   **MF-3.1 (Средний):** сравнение подходов к реализации моделей.
*   **PL-1.2 (Средний):** TensorFlow/Keras.

## Содержание работы

1. Данные + аугментация (CIFAR-10 по умолчанию).
2. Одна CNN — три API.
3. Обучение и сравнение.
4. Выводы про DX/гибкость API.

## Рекомендации по проведению

1. Подчеркните: цель — **не** получить разный accuracy, а понять API.
2. Покажите Functional на примере skip-connection (даже если в задании skip нет).
3. Для Subclassing напомните про `build` / первый `call` и сериализацию.
4. Время: 2–3 академических часа на CIFAR-10.

## Оценка

По **«Критерии_оценки_ЛР_3.1.md»** (5-балльная шкала).

# Лабораторная работа № 3.1: Реализация CNN на TensorFlow/Keras. Сравнение Sequential, Functional и Subclassing API

## Цель работы

*   Научиться строить свёрточные сети в Keras тремя способами: Sequential API, Functional API и Subclassing API (`tf.keras.Model`).
*   Сравнить подходы по удобству реализации, читаемости и гибкости (при одинаковой архитектуре).
*   Применить аугментацию данных и оценить её влияние на обучение.
*   Закрепить навыки работы с TensorFlow/Keras, Pandas, Matplotlib.

> **Примечание.** Перенос обучения (Transfer Learning) и Fine-tuning на предобученных моделях вынесены в **ЛР 4.1** (ResNet).

## Задачи работы

1.  **Подготовка данных:**
    1.  Загрузить датасет (CIFAR-10 или Oxford Flowers 102 — по выбору / указанию преподавателя).
    2.  Разделить на train / val / test.
    3.  Настроить аугментацию для обучающей выборки.
    4.  Создать пайплайн данных (`ImageDataGenerator` или `tf.data`).

2.  **Часть 1: Sequential API**
    1.  Реализовать одну и ту же CNN-архитектуру через `keras.Sequential`.
    2.  Обучить модель, сохранить историю, построить графики.

3.  **Часть 2: Functional API**
    1.  Реализовать **ту же** архитектуру через Functional API (`Input` → слои → `Model`).
    2.  Обучить и сравнить с Sequential.

4.  **Часть 3: Subclassing API**
    1.  Реализовать ту же архитектуру классом, наследующим `tf.keras.Model`.
    2.  Обучить и сравнить с предыдущими вариантами.

5.  **Сравнительный анализ**
    1.  Сравнить test accuracy и время обучения трёх реализаций.
    2.  Сделать выводы о том, когда какой API удобнее (а не ожидать большой разницы accuracy).

## Требования

*   **Инструменты:** Python 3.8+, TensorFlow 2.x, NumPy, Pandas, Matplotlib, Scikit-learn.
*   **Код:** Jupyter Notebook с Markdown-пояснениями.
*   **Аппаратные требования:** CPU допустим для CIFAR-10; GPU желателен.

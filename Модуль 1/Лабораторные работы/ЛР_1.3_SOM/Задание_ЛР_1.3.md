## Задание ЛР 1.3. Реализация SOM для визуализации данных

**Изучение архитектуры самоорганизующихся карт Кохонена (SOM) и их применение для визуализации многомерных данных**

## Цель работы

    Освоить теоретические основы самоорганизующихся карт Кохонена.

    Реализовать алгоритм обучения SOM с использованием только библиотеки NumPy.

    Применить SOM для визуализации многомерных данных (датасет Wine).

    Научиться интерпретировать результаты работы SOM: карту признаков, U-Matrix, компонентные плоскости.

    Сравнить поведение SOM на различных наборах данных.

## Задачи
**1. Реализация SOM**

На основе предоставленного шаблона кода реализовать следующие компоненты самоорганизующейся карты Кохонена:

    Инициализация весов – реализовать инициализацию весов нейронов с использованием случайных выборок из данных.

    Поиск нейрона-победителя (BMU) – реализовать функцию поиска нейрона, наиболее близкого к входному вектору, с использованием евклидовой или косинусной метрики.

    Вычисление коэффициентов соседства – реализовать гауссово окно для определения степени влияния BMU на соседние нейроны.

    Алгоритм обучения – реализовать основной цикл обучения SOM, включающий:

        Экспоненциальное затухание скорости обучения и радиуса соседства

        Стохастическое обновление весов

        Вычисление ошибки квантования

    Предсказание – реализовать функцию определения координат BMU для новых данных.

**2. Эксперименты с SOM**

    Обучить SOM на датасете Wine (13 химических показателей, 3 класса вин).

    Провести эксперименты с различными параметрами SOM:

        Размер сетки (например, 5×5, 10×10, 15×15)

        Начальная скорость обучения (lr = 0.1, 0.5, 1.0)

        Начальный радиус соседства (sigma = 1.0, 3.0, 5.0)

        Количество эпох обучения (100, 300, 500)

        Метрика расстояния (евклидова, косинусная)

    Зафиксировать влияние параметров на качество визуализации и ошибку квантования.

**3. Визуализация результатов**

Реализовать и построить следующие типы визуализаций для обученной SOM:

    Карта SOM с цветовым кодированием кластеров – отображение данных на карте с использованием цветов (красный, синий, зелёный) для различных классов.

    U-Matrix (карта расстояний) – визуализация средних расстояний между соседними нейронами для выявления границ между кластерами.

    Hit Map (карта попаданий) – визуализация плотности распределения данных по нейронам с выделением центров кластеров.

    Компонентные плоскости – визуализация весов каждого признака на карте для интерпретации важности признаков.

    Кривая обучения – график изменения ошибки квантования в процессе обучения.

**4. Анализ и интерпретация результатов**

    Проанализировать, как данные группируются на карте SOM для датасета Wine.

    Определить, какие химические признаки являются наиболее важными для разделения классов (на основе компонентных плоскостей).

    Сравнить качество кластеризации при различных настройках SOM.

    Сделать выводы о способности SOM сохранять топологию данных.

    Предложить рекомендации по выбору параметров SOM для визуализации многомерных данных.

**5. Дополнительное задание (по желанию)**

        Добавить возможность использования различных функций соседства (например, мексиканская шляпа, прямоугольное окно).

    

## Требования к отчёту

Отчёт должен содержать:

    Теоретическое описание алгоритма SOM.

    Описание реализованных метрик расстояния и функций активации.

**2. Описание экспериментов**

    Описание датасета Wine (размерность, количество классов, признаки).

    Архитектура SOM (размер сетки, параметры обучения).

    Способ разделения данных на обучающую и тестовую выборки (80/20).

    Используемые метрики качества (ошибка квантования, визуальное качество кластеризации).

**3. Результаты экспериментов**

    Графики:

        Кривая обучения SOM (ошибка квантования по эпохам).

        Карта SOM с цветовым кодированием для обучающей и тестовой выборок.

        U-Matrix (карта расстояний).

        Hit Map с выделением центров кластеров.

        Компонентные плоскости для всех 13 признаков.

    Таблицы:

        Сравнение ошибки квантования при различных параметрах (размер сетки, lr, sigma).

        Итоговые результаты для различных конфигураций SOM.

**4. Выводы**

    Как SOM визуализирует многомерные данные на двумерной карте.

    Какие параметры SOM наиболее сильно влияют на качество визуализации.

    Как интерпретировать U-Matrix и Hit Map для выявления структуры данных.

    Какие химические признаки Wine являются наиболее дискриминантными (по компонентным плоскостям).

    Рекомендации по применению SOM для визуализации многомерных данных.

    Сравнение с другими методами визуализации (например, PCA, t-SNE).

**5. Приложение**

    Полный код реализованной SOM с комментариями.

    Код для визуализации результатов.

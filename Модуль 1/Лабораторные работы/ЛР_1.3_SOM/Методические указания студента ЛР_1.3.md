### Шаг 3. Реализация поиска нейрона-победителя (`_find_bmu`)

Этот метод находит нейрон, наиболее близкий к входному вектору x.

**Алгоритм:**

1. Преобразуйте веса `self.weights` в плоский массив размером `(m*n, dim)` с помощью `.reshape(-1, self.dim)`.
2. Вычислите расстояние от x до каждого нейрона в зависимости от `self.metric`:
   - Для `'euclidean'`: `dist_sq = np.sum((weights - x)**2, axis=1)`
   - Для `'cosine'`: `dist = 1 - (np.dot(weights, x) / (||weights|| * ||x||))`
3. Найдите индекс нейрона с минимальным расстоянием: `bmu_idx_flat = np.argmin(dist_sq)`
4. Преобразуйте плоский индекс в координаты на сетке:
   - `bmu_i = bmu_idx_flat // self.n`
   - `bmu_j = bmu_idx_flat % self.n`
5. Верните `(bmu_i, bmu_j, минимальное_расстояние)`

**Подсказка:** используйте `np.argmin()` для поиска индекса минимума.

### Шаг 4. Реализация вычисления коэффициентов соседства (`_get_neighborhood`)

Этот метод вычисляет коэффициенты соседства для всех нейронов относительно BMU с использованием гауссова окна.

**Алгоритм:**

1. Создайте матрицы координат:
   - `i_coords = np.arange(self.m).reshape(-1, 1)` — вектор-столбец
   - `j_coords = np.arange(self.n).reshape(1, -1)` — вектор-строка
2. Вычислите квадрат расстояния от каждого нейрона до BMU:
   - `dist_sq = (i_coords - bmu_i)**2 + (j_coords - bmu_j)**2`
3. Примените гауссово окно:
   - `neighborhood = np.exp(-dist_sq / (2 * sigma**2))`
4. Верните матрицу коэффициентов соседства размером `(m, n)`

**Подсказка:** используйте `np.exp()` для вычисления экспоненты. Обратите внимание на broadcasting при вычислении расстояний.

### Шаг 5. Реализация основного алгоритма обучения (`fit`)

Этот метод реализует основной цикл обучения SOM.

**Алгоритм:**

Для каждой эпохи:
1. Вычислите текущие значения lr и sigma с экспоненциальным затуханием:
   - `lr = self.initial_lr * np.exp(-epoch / epochs)`
   - `sigma = self.initial_sigma * np.exp(-epoch / epochs)`
2. Перемешайте данные: `indices = np.random.permutation(n_samples)`
3. Для каждого образца в перемешанном порядке:
   - Найдите BMU с помощью `_find_bmu(x)`
   - Вычислите коэффициенты соседства с помощью `_get_neighborhood(bmu_i, bmu_j, sigma)`
   - Обновите веса всех нейронов:
     - `delta = lr * neighborhood[..., np.newaxis] * (x - self.weights)`
     - `self.weights += delta`
4. Вычислите ошибку на эпохе с помощью `_compute_quantization_error(X)`
5. Сохраните ошибку в `self.train_errors`
6. Если передана тестовая выборка, вычислите и сохраните ошибку на тесте
7. Выводите прогресс каждые 10% эпох

**Подсказки:**
- Для broadcasting добавьте новую ось: `neighborhood[..., np.newaxis]`
- Размерность `neighborhood` — `(m, n)`, размерность `weights` — `(m, n, dim)`
- Для перемешивания: `indices = np.random.permutation(n_samples)`

## 3. Рекомендации по отладке

### 3.1. Проверка реализации

- Для проверки используйте небольшой датасет (например, 100 образцов из Wine) и малое число эпох (10-20).
- Если ошибка квантования не уменьшается, проверьте:
  - Правильность вычисления расстояний в `_find_bmu`
  - Корректность обновления весов в `fit`
  - Наличие экспоненциального затухания lr и sigma

### 3.2. Отладка визуализаций

- Убедитесь, что цвета соответствуют классам (красный → класс 0, синий → класс 1, зелёный → класс 2).
- Проверьте, что на карте SOM отображаются все образцы.
- Для U-Matrix убедитесь, что значения нормализованы.

### 3.3. Частые ошибки

1. **Неправильная инициализация весов**: веса должны быть выборками из данных, а не случайными числами.
2. **Ошибка в поиске BMU**: перепутаны i и j при преобразовании индекса.
3. **Неправильная размерность**: `neighborhood` имеет размерность (m, n), а `weights` — (m, n, dim).
4. **Отсутствие затухания**: lr и sigma должны уменьшаться с эпохами.
5. **Неправильная нормализация**: перед обучением данные должны быть стандартизированы.

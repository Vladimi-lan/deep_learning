**Шаг 3. Реализация класса Layer**

Найдите класс Layer. Реализуйте:

    __init__: инициализация весов и смещений (используйте np.random.randn; для ReLU используйте He-инициализацию: np.random.randn(n_input, n_output) * np.sqrt(2.0 / n_input)).

    forward:

        Сохраните вход X в self.input.

        Вычислите Z = np.dot(X, self.W) + self.b и сохраните в self.Z.

        Примените активацию в зависимости от self.activation:

            'relu': np.maximum(0, Z)

            'softmax': стабильный softmax (вычтите максимум по строкам для численной устойчивости)

            'linear': Z

        Сохраните результат в self.output и верните его.

    backward:

        Вычислите dZ в зависимости от активации:

            ReLU: dZ = dout * (self.Z > 0)

            Softmax: dZ = dout (градиент уже содержит (probs - y_one_hot)/batch_size)

            Linear: dZ = dout

        Вычислите градиенты:

            dW = np.dot(self.input.T, dZ) / batch_size

            db = np.sum(dZ, axis=0, keepdims=True) / batch_size

        Градиент по входу: dinput = np.dot(dZ, self.W.T)

        Обновите параметры: self.W -= learning_rate * dW, self.b -= learning_rate * db

        Верните dinput.

**Шаг 4. Реализация класса MLP**

    __init__: создайте список self.layers из экземпляров Layer для каждой пары размеров из layer_sizes.

    forward: последовательно примените все слои к входу X, верните выход последнего.

    backward: передайте градиент через слои в обратном порядке, вызывая layer.backward().

    train_step:

        Получите вероятности: probs = self.forward(X_batch).

        Преобразуйте метки в one-hot: to_categorical(y_batch, num_classes=10).

        Вычислите кросс-энтропию: loss = -np.mean(np.sum(y_one_hot * np.log(probs + 1e-8), axis=1)).

        Градиент для выходного слоя: dout = (probs - y_one_hot) / X_batch.shape[0].

        Вызовите self.backward(dout, learning_rate).

        Верните loss.

    predict: примените forward и верните np.argmax по оси 1.

    accuracy: сравните предсказания с истинными метками и верните среднее значение.

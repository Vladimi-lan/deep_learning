# Лабораторная работа № 4.2: Реализация простого детектора объектов (упрощённый YOLO)

## Цель работы

*   Познакомиться с задачей детекции объектов и идеей YOLO (предсказание bounding box и класса за один проход сети).
*   Реализовать упрощённый одностадийный детектор на свёрточной сети.
*   Подготовить синтетический датасет геометрических фигур.
*   Обучить модель и визуализировать предсказанные рамки на тестовых изображениях.

## Задачи работы

1.  **Синтетический датасет:**
    1.  Сгенерировать изображения (например, 64×64 или 128×128) с фигурами: круг, прямоугольник, треугольник.
    2.  Для каждого объекта сохранить метку класса и bounding box в формате `(cx, cy, w, h)` (нормализованные координаты) или `(xmin, ymin, xmax, ymax)`.
    3.  Разделить выборку на train / val / test.

2.  **Модель (упрощённый YOLO-like):**
    1.  Реализовать CNN-backbone (несколько Conv + Pool / Stride).
    2.  Добавить выходную голову: класс (softmax/sigmoid) + координаты бокса (4 числа).
    3.  Для упрощения допускается **один объект на изображение** (single-object detection).

3.  **Обучение:**
    1.  Функция потерь: классификация (`CrossEntropy` / `BCE`) + регрессия бокса (`MSE` / `SmoothL1`).
    2.  Обучить модель, отслеживая loss на train/val.
    3.  Подобрать веса слагаемых потерь (`λ_cls`, `λ_box`).

4.  **Визуализация и оценка:**
    1.  Отрисовать предсказанные и истинные bounding boxes (OpenCV или Matplotlib).
    2.  Оценить качество: accuracy класса и IoU боксов (средний IoU на тесте).
    3.  Сделать выводы об ошибках модели.

## Требования

*   **Инструменты:** Python 3.8+, PyTorch, NumPy, Matplotlib, OpenCV (`opencv-python`), Pillow.
*   **Код:** Jupyter Notebook с Markdown-пояснениями.
*   **Аппаратные требования:** CPU допустим; GPU ускоряет эксперименты.

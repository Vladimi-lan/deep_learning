# Методические указания для студентов по выполнению ЛР № 4.2

## Введение

Вы реализуете **упрощённый одностадийный детектор** в духе YOLO: сеть за один проход предсказывает класс объекта и координаты bounding box. Чтобы упростить постановку, на каждом изображении будет **ровно один** объект (круг / прямоугольник / треугольник).

## Подготовка к работе

```bash
pip install torch torchvision numpy matplotlib opencv-python pillow
```

Ноутбук: `ЛР_4.2_YOLO_Simple.ipynb`.

## Ход выполнения работы

### 1. Генерация датасета

1. Создайте функцию, рисующую случайную фигуру на холсте фиксированного размера.
2. Сохраните для каждого примера:
   - изображение;
   - `class_id` ∈ {0, 1, 2};
   - бокс в нормализованном виде `(cx, cy, w, h)` относительно ширины/высоты изображения.
3. Сгенерируйте, например, 2000–5000 train и 400–1000 val/test примеров.

**Вопрос 1.** Почему для учебной детекции удобен синтетический датасет?

### 2. Модель

Рекомендуемая схема (можно изменить):

*   3–4 блока `Conv2d → BatchNorm → ReLU → MaxPool`
*   `AdaptiveAvgPool2d(1)` или `Flatten`
*   две головы: `cls` (3 логита) и `box` (4 числа, обычно через `sigmoid` для нормализованных координат)

### 3. Loss и обучение

```text
L = λ_cls * L_cls + λ_box * L_box
```

*   `L_cls` — CrossEntropyLoss
*   `L_box` — SmoothL1Loss / MSELoss
*   Начните с `λ_cls = 1.0`, `λ_box = 5.0` и подберите эмпирически

**Вопрос 2.** Что будет, если `λ_box` слишком мал?

### 4. Метрики и визуализация

1. Реализуйте IoU для предсказанного и истинного бокса.
2. На тесте посчитайте mean IoU и accuracy класса.
3. Нарисуйте 6–12 примеров с GT (зелёный) и Pred (красный).

**Вопрос 3.** Чем IoU лучше простой MSE по координатам как метрика качества рамки?

## Типичные проблемы

1. **Боксы «не сходятся»:** увеличьте `λ_box`, проверьте нормализацию координат и `sigmoid` на выходе.
2. **Класс учится, рамка нет:** отдельно логируйте `L_cls` и `L_box`.
3. **Путаница форматов бокса:** везде используйте один формат (`cxcywh` или `xyxy`) и явно конвертируйте при отрисовке.

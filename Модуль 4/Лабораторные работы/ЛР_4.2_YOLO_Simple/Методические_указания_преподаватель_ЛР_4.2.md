# Методические указания для преподавателей по проведению ЛР № 4.2

## Тема и цель работы

**Тема:** Упрощённый детектор объектов (YOLO-like) на синтетических фигурах.

**Цель:** Дать практику одностадийной детекции без сложности полного YOLO (якоря, сетка S×S, NMS для многих объектов).

## Компетенции

*   **DL-1.4 (Средний):** специализированные CNN для CV-задач (детекция).
*   **PL-1.2 (Средний):** PyTorch, генерация данных, визуализация (OpenCV/Matplotlib).

## Содержание работы

1. Генератор синтетических изображений + боксы.
2. CNN с головами class/box.
3. Комбинированный loss, обучение.
4. IoU + визуализация предсказаний.

## Рекомендации по проведению

1. Напомнить отличие classification / localization / detection.
2. Объяснить IoU на доске (пересечение / объединение).
3. Подчеркнуть: это **учебный** single-object YOLO, не production YOLOv8.
4. Время: 2–4 академических часа; на CPU выполнимо.

## Оценка

По **«Критерии_оценки_ЛР_4.2.md»**.

Ориентир: после обучения mean IoU ≳ 0.5–0.7 и class accuracy ≳ 0.85 на простой синтетике — хороший результат.

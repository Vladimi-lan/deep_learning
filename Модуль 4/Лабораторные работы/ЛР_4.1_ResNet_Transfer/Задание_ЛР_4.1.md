# Лабораторная работа № 4.1: Трансфер обучения (Transfer Learning) и Fine-tuning на предобученной ResNet

## Цель работы

*   Научиться применять трансфер обучения для классификации изображений на небольшом датасете.
*   Освоить заморозку слоёв предобученной ResNet, замену классификационной головы и дообучение (fine-tuning).
*   Сравнить качество моделей: feature extraction (замороженный backbone), fine-tuning и обучение с нуля.
*   Закрепить навыки работы с PyTorch / TorchVision, подготовкой данных и визуализацией результатов.

## Задачи работы

1.  **Подготовка данных:**
    1.  Загрузить датасет Oxford Flowers 102 (или эквивалентный набор с ограниченным числом примеров на класс).
    2.  Выполнить разделение на train / val / test с сохранением баланса классов.
    3.  Настроить аугментацию для обучающей выборки и нормализацию под ImageNet (mean/std).
    4.  Создать `DataLoader`-ы.

2.  **Часть 1. Feature extraction (Transfer Learning):**
    1.  Загрузить предобученную `resnet18` (веса ImageNet) из `torchvision.models`.
    2.  Заморозить все слои backbone.
    3.  Заменить последний полносвязный слой под число классов датасета (102).
    4.  Обучить только голову классификации.
    5.  Сохранить историю обучения и оценить качество на тесте.

3.  **Часть 2. Fine-tuning:**
    1.  Разморозить часть (или все) слоёв backbone.
    2.  Продолжить обучение с уменьшенным learning rate.
    3.  Сравнить качество с этапом feature extraction.

4.  **Часть 3. Обучение с нуля (сравнение):**
    1.  Обучить ту же архитектуру ResNet18 **без** предобученных весов (или с `weights=None`).
    2.  Сравнить точность и скорость сходимости с Transfer Learning / Fine-tuning.

5.  **Анализ:**
    1.  Построить графики loss/accuracy.
    2.  Сделать выводы о преимуществах трансферного обучения на малом датасете.

# Методические указания для студентов по выполнению ЛР № 4.1

## Введение

В этой работе вы применяете **Transfer Learning** и **Fine-tuning** на предобученной ResNet18 для классификации цветов Oxford Flowers 102. На малом датасете обучение «с нуля» обычно хуже и медленнее, чем перенос признаков ImageNet.

## Подготовка к работе

1. Python 3.8+.
2. Установка библиотек:
   ```bash
   pip install torch torchvision numpy matplotlib scikit-learn pillow
   ```
3. Ресурсы: ноутбук `ЛР_4.1_ResNet_Transfer.ipynb`, GPU рекомендуется.
4. Датасет скачивается в ноутбуке (не храните большие архивы в git).

## Ход выполнения работы

### 1. Подготовка данных

1. Загрузите Oxford Flowers 102 (`torchvision.datasets.Flowers102` или ручная загрузка).
2. Разделите данные / используйте штатные split'ы.
3. Для train: аугментации (`RandomResizedCrop`, `RandomHorizontalFlip` и т.п.).
4. Для val/test: `Resize` + `CenterCrop`.
5. Нормализация ImageNet: `mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`.

**Вопрос 1.** Почему для предобученной ResNet нужна именно ImageNet-нормализация?

### 2. Feature extraction

1. `resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)`.
2. Заморозьте параметры: `param.requires_grad = False` для backbone.
3. Замените `model.fc` на `nn.Linear(in_features, num_classes)`.
4. Обучите 5–10 эпох с LR ≈ `1e-3`.
5. Оцените accuracy на тесте.

**Вопрос 2.** Какие слои обучаются на этом этапе и почему это ускоряет обучение?

### 3. Fine-tuning

1. Разморозьте последние блоки (например, `layer3`, `layer4`) или всю сеть.
2. Уменьшите LR до `1e-4` … `1e-5`.
3. Дообучите несколько эпох.
4. Сравните test accuracy с feature extraction.

**Вопрос 3.** Почему при fine-tuning learning rate обычно уменьшают?

### 4. Обучение с нуля

1. Создайте ResNet18 с `weights=None`.
2. Обучите сопоставимое число эпох.
3. Сравните с Transfer Learning / Fine-tuning по accuracy и сходимости.

## Типичные проблемы

1. **Низкая точность при TL:** проверьте нормализацию ImageNet и что голова создана с правильным `num_classes`.
2. **OOM:** уменьшите `batch_size`, используйте `resnet18` (не 50/101).
3. **Fine-tuning «ломает» модель:** слишком большой LR — уменьшите до `1e-5`.
